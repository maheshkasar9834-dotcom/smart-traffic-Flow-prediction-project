# Smart Traffic Flow Prediction 🚦
## Overview
This project uses machine learning techniques to predict traffic flow and road congestion based on traffic data analysis.

## Features
- Traffic flow prediction
- Congestion analysis
- Smart traffic management
- Data visualization                        

## Technologies Used
- Python
- Machine Learning
-  Numpy
-  Pandas
- linear regression
- Matplotlib
